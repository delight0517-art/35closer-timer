Auto-Sleep Guardian

작업 중엔 각성(Keep-Awake), 끝나면 즉시 절전

AI 에이전트 프로세스, Xcode/Flutter 빌드, 3D 렌더링이 가동 중일 때는 Caffeinate로 시스템이 잠들지 않도록 방어합니다. 작업이 완료되어 CPU가 유휴(Idle) 상태에 도달하면 Mac을 자동으로 절전 모드로 전환합니다.

터미널 해커를 위한 35closerctl CLI

야간 빌드 스크립트나 배치 작업의 마지막 줄에 한 줄만 덧붙이세요. 터미널 파이프라인에서 완벽하게 제어할 수 있습니다.

zsh — 35closerctl
# 대규모 빌드 완료 후 Mac 자동 절전 대기
$ npm run build && 35closerctl sleep --after-idle

# 가디언 상태 즉시 확인
$ 35closerctl status
✓ Guardian active · idleQuiet: 12m · sleepArm: ready
