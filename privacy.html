Privacy Policy

최종 업데이트: 2026-09-14

Last updated: 2026-09-14

35Closer Timer("본 앱")는 개인 사용자의 로컬 PC에서 동작하는 타이머/자동 절전 데스크톱 앱입니다. 본 앱은 개발사 서버로 어떠한 데이터도 전송하지 않습니다.

35Closer Timer ("the App") is a timer and auto-sleep desktop app that runs locally on your PC. The App does not transmit any data to the developer's servers — there are none.

수집하는 정보

Information We Collect

본 앱은 사용자 계정, 이메일, 위치 정보 등 개인 식별 정보를 수집하지 않습니다. 다음 정보는 오직 사용자의 로컬 PC(%APPDATA%\35CloserTimer)에만 저장되며 외부로 전송되지 않습니다:

The App does not collect personal identifiers such as your name, email, or location. The following information is stored only on your local PC (%APPDATA%\35CloserTimer) and is never sent externally:

  • 타이머 설정 및 사용 기록(오늘/이번 주 리포트용)
  • Timer settings and usage history (for daily/weekly reports)
  • 키보드/마우스 입력 여부(자리비움 감지용 — 입력 "내용"은 절대 기록하지 않고, 마지막 입력 시각만 확인)
  • Whether keyboard/mouse input occurred (for idle detection only — never the content of input, only the timestamp of last activity)
  • 앱 자체의 진단 로그(오류/이벤트 로그, 문제 해결 목적)
  • The App's own diagnostic/event logs (for troubleshooting)

선택적 기능: 텔레그램 알림

Optional Feature: Telegram Notifications

사용자가 직접 자신의 텔레그램 봇 토큰을 등록한 경우에만, 타이머/절전 관련 알림을 사용자 본인의 텔레그램 봇으로 전송할 수 있습니다. 이 기능은 기본적으로 꺼져 있으며, 이때 통신은 사용자 본인이 소유한 텔레그램 봇과 사용자 기기 사이에서만 이루어집니다 — 개발사는 이 통신을 중계하거나 열람하지 않습니다.

Only if you register your own Telegram bot token, the App can send timer/sleep-related notifications to your own Telegram bot. This feature is off by default. Communication happens directly between your device and your own Telegram bot — the developer never relays or views these messages.

데이터 공유

Data Sharing

본 앱은 어떠한 제3자와도 사용자 데이터를 공유하거나 판매하지 않습니다. 광고 SDK, 분석(Analytics) SDK를 포함하지 않습니다.

The App does not share or sell user data with any third party. It contains no advertising SDK and no analytics SDK.

시스템 권한

System Permissions

본 앱은 절전/화면 끄기 등 Windows 전원 관리 기능을 사용하기 위해 시스템 API에 접근합니다. 이 접근은 오직 사용자가 설정한 타이머/자동 절전 기능을 실행하는 데에만 사용되며, 항상 취소 가능한 확인 절차를 거칩니다.

The App accesses Windows power-management APIs to turn off the display or put the PC to sleep. This access is used solely to run the timer/auto-sleep feature you configure, and always goes through a cancellable confirmation step.
